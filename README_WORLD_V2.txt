MEGANOTRPG — World v2

Сделано по новой структуре вкладки «Мир»:

1. Верхняя карточка мира теперь кликабельна.
   Она открывает «Содержание мира» с отдельными панелями:
   - Правила мира
   - История мира
   - Фракции
   - Лор и особенности
   Эти разделы уже живут в Supabase и дальше могут добавляться GM без переделки интерфейса.

2. Локации:
   - на главном экране показываются только 2 последние по updated_at;
   - кнопка «Все» открывает полный список;
   - каждая локация открывает отдельную страницу.

3. Достижения игроков:
   - отдельный компактный список;
   - достижение может быть связано с персонажем;
   - хранится в таблице achievements.

4. Последние изменения:
   - НЕ автоматический журнал;
   - отдельная таблица campaign_updates;
   - только ручные публикации GM: «Изменение» или «Объявление»;
   - если у участника role='gm', появляется кнопка «+ Запись» и редактор.

Новые таблицы Supabase уже созданы:
- world_sections
- world_articles
- locations
- achievements
- campaign_updates

Для игроков включено чтение содержимого своей кампании.
Запись/редактирование в эти таблицы разрешены только campaign_members.role='gm'.

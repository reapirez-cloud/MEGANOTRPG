MEGANOTRPG — Character Resources v11.1

Исправление после v11.

Что было:
- HP уже существовали в «Листе», но редактировались только через большой редактор листа.
- Ячейки технически уже работали и списывались в чате, но на странице персонажа были почти не видны.

Что теперь:
- Персонаж → Лист → «♥ Ресурсы».
- Персонаж → Заклинания → зелёная панель «Ячейки».
- Видно «осталось / максимум» для каждого уровня.
- GM/Owner через «Ресурсы» задаёт:
  - максимум HP;
  - текущие HP;
  - временные HP;
  - максимум ячеек 1–9.
- Потраченные ячейки вручную назначать не надо: приложение само списывает их при касте.
- «Дать отдых» восстанавливает HP и все ячейки.

Установка:
1. Положи apply_v11_1.mjs в корень MEGANOTRPG рядом с package.json.
2. Выполни:
   node apply_v11_1.mjs
   npm run build
3. Если сборка успешна:
   git add .
   git commit -m "Expose character HP and spell slot resources"
   git push origin main

Локальный запуск:
npm run dev

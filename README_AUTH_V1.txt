MEGANOTRPG — Auth Foundation v1

Что изменилось:
- при первом открытии Supabase создаёт отдельного anonymous auth user;
- каждый браузер/устройство получает собственный auth.uid;
- игрок один раз выбирает уникальное имя;
- имя хранится в таблице profiles, а не в localStorage;
- сообщения больше не доверяют имени, присланному браузером;
- БД сама подставляет user_id и display_name отправителя;
- комнаты и сообщения теперь читают только авторизованные участники demo-кампании;
- новый профиль автоматически добавляется в demo-кампанию как player.

ВАЖНО:
Перед запуском включи Anonymous Sign-Ins:
Supabase Dashboard → Authentication → Providers → Anonymous Sign-Ins → Enable.

Ограничение этой версии:
anonymous account привязан к конкретному браузеру. Если очистить данные браузера
или открыть другой браузер — это будет новый пользователь.
Это специально для текущего теста. Позже Telegram initData заменит этот способ входа,
а таблицы profiles / campaign_members / RLS останутся полезной основой.

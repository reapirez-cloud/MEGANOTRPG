MEGANOTRPG — Permissions + Delete v11.3

Supabase уже обновлён мной. SQL руками запускать НЕ нужно.

Права после проверки:

GM / владелец:
- создаёт, редактирует и удаляет мир, статьи, локации, разделы локаций,
  переходы, достижения, события;
- создаёт, редактирует и удаляет персонажей;
- создаёт/удаляет игровые чаты и назначает доступ игрокам;
- создаёт/удаляет общий арт кампании;
- создаёт/редактирует/удаляет предметы, особенности, заклинания;
- меняет HP и ячейки;
- даёт долгий отдых;
- удаляет записи и комментарии дневника.

Игрок:
- загружает фото только своего назначенного персонажа;
- читает свой инвентарь;
- может надеть/снять только предмет категории equipment;
- сервер проверяет допустимые слоты и конфликт двуручного оружия с руками;
- НЕ может создавать/редактировать/удалять предметы;
- может редактировать существующие заклинания и менять «Подготовлено»;
- НЕ может создавать и удалять заклинания;
- НЕ может менять ячейки;
- может писать дневник;
- может комментировать;
- НЕ может удалять записи/комментарии;
- пишет в игровой чат только если GM дал право «Писать».

Что добавляет интерфейс:
- Персонажи → Редактировать → «Удалить персонажа».
- Игровой чат → ⚙ → «Удалить игровой чат».
- Мир → открыть объект → Изменить → «Удалить».
  Это работает для разделов, записей, локаций, разделов локации,
  переходов, достижений и событий.
- Общая вкладка «Арты»: добавление/удаление только GM/владелец.
- Игрок больше не видит «+ Заклинание» и кнопку удаления заклинания.
  Редактирование и «Подготовлено» остаются.
- У игрока больше нет удаления собственной дневниковой записи/комментария.

Удаление двухшаговое:
1. Нажать «Удалить».
2. Нажать ещё раз «Точно удалить?».

Каскад:
- удаление игрового чата удаляет его сообщения;
- удаление раздела мира удаляет его статьи;
- удаление локации удаляет её подлокации, разделы и ссылки;
- удаление персонажа удаляет лист, инвентарь, заклинания и дневник.

Установка:
1. Распакуй архив.
2. Положи apply_v11_3.mjs в корень MEGANOTRPG рядом с package.json.
3. PowerShell:
   node apply_v11_3.mjs
   npm run build

4. Если сборка зелёная:
   git add .
   git commit -m "Add manager deletes and tighten player permissions"
   git push origin main

Локальный запуск:
npm run dev

MEGANOTRPG — Social Characters + Long Press v11.4

Supabase уже обновлён мной. SQL руками запускать НЕ нужно.

Что меняется:

1. Ник в чате теперь кликабельный
- Если сообщение написано от персонажа, нажми на ник или аватар.
- Откроется профиль этого персонажа.
- GM/Owner без персонажа остаётся обычной ролью и не ведёт на профиль.
- Если старое сообщение принадлежит персонажу, который уже НЕ активен у другого игрока,
  обычному игроку профиль по нему не откроется. GM/Owner всё равно видит всех.

2. Другие персонажи становятся видимыми
Обычный игрок теперь видит:
- ВСЕХ своих назначенных персонажей;
- у каждого другого игрока — ТОЛЬКО его активного персонажа.

То есть скрытые/неактивные персонажи другого игрока не раскрываются.

3. Полный просмотр активного персонажа другого игрока
Можно открыть:
- дневник;
- инвентарь;
- экипировку;
- лист;
- заклинания;
- HP и ячейки в режиме просмотра;
- особенности.

Редактирование при этом остаётся по старым правам:
чужого персонажа игрок только смотрит.

4. Зажатие вместо нагромождения кнопок
На телефоне:
- зажми карточку персонажа (GM/Owner);
- зажми игровой чат (GM/Owner).

Появится нижнее меню.

Персонаж:
- Открыть персонажа
- Редактировать
- Сделать активным (если актуально)
- Удалить персонажа

Игровой чат:
- Открыть чат
- Настройки
- Удалить чат

То есть больше не нужно делать странную схему «Удалить → Точно удалить?» внутри самой карточки.
Само долгое нажатие уже является намеренным действием, а удаление лежит красным пунктом меню.

5. Права
v11.4 автоматически запускает v11.3, если ты его ещё не применял локально.
Поэтому сохраняются ограничения:
- создавать общий контент может только GM/Owner;
- игрок меняет фото своего персонажа;
- экипирует разрешённые предметы;
- редактирует/подготавливает существующие заклинания, но не ячейки;
- пишет дневник;
- не удаляет общий контент.

Установка:
1. Распакуй архив.
2. Положи в корень MEGANOTRPG рядом с package.json только:
   - apply_v11_4.mjs

3. PowerShell:
   node apply_v11_4.mjs
   npm run build

4. Если сборка зелёная:
   git add .
   git commit -m "Add active character visibility and long press menus"
   git push origin main

Проверка:
- зайди игроком A;
- игрок B должен показываться только своим активным персонажем;
- открой персонажа B и проверь дневник/инвентарь/лист/заклинания;
- в чате нажми на ник B;
- GM зажимает карточку персонажа;
- GM зажимает игровой чат.

Локальный запуск:
npm run dev

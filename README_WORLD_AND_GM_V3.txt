MEGANOTRPG — World + GM v3

База уже обновлена.

Что изменено:
- выдуманный сеттинг очищен; demo-кампания теперь называется «Новая кампания»;
- GM сам создаёт разделы мира и записи внутри них;
- GM сам создаёт корневые локации;
- внутри локации GM может создавать подлокации;
- у каждой локации есть отдельные смысловые разделы;
- в раздел локации можно добавить переход на любую другую локацию;
- на главной показываются только 2 последние корневые локации;
- достижения создаёт GM;
- объявления/последние изменения пишет GM вручную;
- игрок вводит только своё имя профиля;
- персонажей создаёт и прикрепляет к игрокам GM;
- у игрока может быть несколько персонажей;
- активного персонажа выбирает GM;
- в чате имя выглядит как «Персонаж (Игрок)»;
- аватар чата берётся из карточки активного персонажа;
- короткие сообщения имеют минимальную ширину и больше не схлопываются.

Первичная настройка:
если в demo-кампании ещё нет GM, в приложении появится одноразовая кнопка «Стать GM».
Первый участник, который её нажмёт, станет GM. После этого повторно забрать роль нельзя.

Пока изображения задаются URL. Следующий этап — Supabase Storage и загрузка файлов с телефона.

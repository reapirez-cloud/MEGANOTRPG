MEGANOTRPG — Mobile Dice v11.2

Исправляет управление броском с телефона.

Было:
- поле «Количество» уже содержит 1, поэтому с мобильной клавиатуры легко получить 11, 12 и т.п.;
- на некоторых мобильных клавиатурах у type=number вообще нет удобного минуса для отрицательного модификатора.

Теперь клавиатура для этих двух параметров вообще не нужна.

Количество:
[-]   1   [+]
и быстрые кнопки:
1  2  3  4  5

Модификатор:
[-]   0   [+]
и быстрые:
-5  -2  -1  0  +1  +2  +5

Можно тапать +/- сколько угодно:
- количество: 1–20;
- модификатор: -100…+100.

Установка:
1. Положи apply_v11_2.mjs в корень MEGANOTRPG рядом с package.json.
2. PowerShell:
   node apply_v11_2.mjs
   npm run build
3. Если сборка зелёная:
   git add .
   git commit -m "Fix mobile dice controls"
   git push origin main

Локально:
npm run dev

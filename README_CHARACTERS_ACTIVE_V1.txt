MEGANOTRPG — Characters + Active Character v1

Что сделано в базе:
- таблица characters;
- у одного игрока может быть несколько персонажей;
- campaign_members.active_character_id хранит активного персонажа отдельно для кампании;
- chat_messages.character_id привязывает каждое сообщение к персонажу, который был активен в момент отправки;
- база сама берёт имя и avatar_url активного персонажа;
- нельзя отправить игровое сообщение без активного персонажа;
- существующим игрокам автоматически создан стартовый персонаж из их текущего имени.

Что сделано в интерфейсе:
- короткие сообщения больше не схлопываются в узкий высокий пузырь;
- минимальная ширина пузыря ~156px, длинный текст растягивает его до лимита;
- рядом с сообщениями есть аватар персонажа;
- в Чатах и внутри комнаты есть переключатель активного персонажа;
- вкладка Персонажи теперь берёт реальные данные из Supabase;
- можно создать несколько своих персонажей;
- можно выбрать, какой из них активный;
- аватар в карточке и чате берётся из одного character.avatar_url.

Пока аватар задаётся ссылкой на изображение.
Следующий логичный этап — Supabase Storage и загрузка картинки прямо с телефона.

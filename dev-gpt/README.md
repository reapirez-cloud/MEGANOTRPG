# dev-gpt

Изолированная рабочая зона для аудита жреца (Cleric) в ветке `dev-gpt`.

## Цель

- создать исполняемого тестового персонажа класса Жрец;
- прогнать базовую прогрессию 1–20;
- проверить persistent choices, ресурсы, восстановление, заклинания и действия;
- проверить все 14 доменов на реальные CE/runtime-контракты;
- исправлять найденные дефекты только в ветке `dev-gpt`;
- не менять `dev` или `main` до отдельного решения владельца проекта.

## Граница автоматизации

Тест считает обязательными только факты, которыми по контракту владеет Character Engine / persistent runtime: уровни открытия, постоянные выборы, ресурсы, восстановление, подготовка и доступ к заклинаниям, deterministic grants и стоимость finite-resource действий. Сценарная легальность, цели, попадания и action economy остаются за ГМ.

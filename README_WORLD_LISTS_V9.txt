MEGANOTRPG — World lists v9

Что меняется:
- На главной вкладке «Мир» показываются только 3 последних достижения.
- Рядом есть кнопка «Все» → отдельный экран со всеми достижениями.
- На главной вкладке «Мир» показываются только 3 последних события.
- Рядом есть кнопка «Все» → отдельный экран со всеми событиями.
- Списки сортируются по дате: самые свежие сверху.
- Добавление и редактирование остаётся доступно GM/Owner.
- База данных не меняется.

Установка:
1. Распакуй архив.
2. Скопируй apply_world_v9.mjs в корень MEGANOTRPG
   (туда, где package.json).
3. Открой PowerShell в папке проекта.
4. Выполни:
   node apply_world_v9.mjs
5. Затем:
   npm run build
6. Если сборка успешна:
   git add .
   git commit -m "Show latest world events and achievements"
   git push origin main

Скрипт сам создаёт резервную копию:
src/pages/World.tsx.v9.bak

После успешной проверки её можно удалить перед коммитом:
del src\pages\World.tsx.v9.bak

Локальный запуск:
npm run dev

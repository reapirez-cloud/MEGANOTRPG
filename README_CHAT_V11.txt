Supabase уже обновлён мной. SQL руками запускать НЕ нужно.

Что входит:

1. Флуд
- Один постоянный «Флуд».
- Он всегда первым во вкладке «Чаты».
- Доступен всем участникам кампании.

2. Игровые чаты
- GM/Owner нажимает «+ Новый» в разделе «Игра».
- Новый игровой чат изначально видят только GM/Owner.
- Внутри чата есть кнопка ⚙.
- В настройках GM выбирает каждому игроку отдельно:
  - Читать
  - Писать
- Если включить «Писать», чтение включается автоматически.

3. Персонаж под диалогом
- Под сообщениями показана строка «Твой персонаж».
- Нажатие открывает профиль персонажа.
- Назад из персонажа возвращает именно в тот чат.

4. Композер
- Слева кнопка «+» действий.
- По центру поле текста.
- Справа отправка.

5. Кубики
- d4 / d6 / d8 / d10 / d12 / d20 / d100.
- Количество кубов.
- Модификатор от -100 до +100.
- Результат считает сервер и сразу публикует его сообщением в чат.

6. Подготовленные заклинания
- В редакторе заклинания есть «Подготовлено».
- Подготовленные заклинания зелёные.
- В меню действий чата показываются только подготовленные.
- В самом заклинании можно выбрать:
  - Кантрип · без ячейки
  - Ячейка
- Для «Ячейка» выбирается уровень ячейки 1–9.
- При использовании приложение само списывает ячейку.
- Если ячейки закончились, заклинание нельзя применить через чат.

7. Ячейки
- GM открывает лист персонажа → Заклинания.
- Там появились уровни ячеек 1–9.
- GM задаёт максимум каждой ячейки.
- Потраченные считаются автоматически.

8. Долгий отдых
- В ⚙ настройках игрового чата GM видит персонажей участников.
- «Дать отдых»:
  - HP = максимум;
  - временные HP = 0;
  - спасброски от смерти сбрасываются;
  - все ячейки восстанавливаются.
- Игрок сам себе отдых дать не может.

Установка:
1. Распакуй архив.
2. Внутри папка MEGANOTRPG_ChatGame_v11.
3. Скопируй папку src из неё поверх src своего проекта с заменой файлов.
4. Затем в PowerShell из C:\Users\VI\Desktop\MEGANOTRPG:

npm run build

5. Если сборка успешна:

git add .
git commit -m "Build game chat permissions dice spells and rest"
git push origin main

6. После Vercel-деплоя проверяй уже в Telegram.

Локальный запуск:
npm run dev

MEGANOTRPG — Character Cards / D&D Sheet v5

Что добавлено:
- настоящий D&D-лист вместо заглушки;
- характеристики, модификаторы, спасброски, навыки, КД, HP, скорость, мастерство, кости хитов, death saves;
- раса/вид, предыстория, мировоззрение, опыт;
- владения, языки, чувства, черты личности, идеалы, привязанности, слабости, backstory и заметки;
- фиты / классовые / расовые особенности отдельным списком;
- инвентарь списком с количеством, весом, equipped, описанием и местом под арт предмета;
- заклинания отдельной вкладкой только если GM/владелец включил spellcasting в листе;
- игрок, которому прикреплён персонаж, может сам добавлять/редактировать/удалять заклинания;
- игрок может менять арт своего персонажа через отдельный безопасный RPC;
- дневник теперь настоящий Supabase: игрок пишет записи, но после публикации их НЕЛЬЗЯ редактировать;
- запись дневника можно только удалить;
- к записям можно оставлять комментарии; свои комментарии можно удалять, GM/владелец может удалять любые;
- GM и владелец управляют полным листом, инвентарём и особенностями.

Права:
- OWNER / GM: полный лист + инвентарь + фиты + заклинания + дневник + арт.
- назначенный PLAYER: только арт своего персонажа + его список заклинаний + дневник.
- другие игроки не получают доступ к чужому листу персонажа.

Важно:
Арт пока хранится как URL. Следующий этап — Supabase Storage и загрузка картинок прямо с телефона.

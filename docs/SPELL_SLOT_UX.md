# Spell slot UX

The spell slot meter makes fallback casting explicit without changing spell-casting mechanics.

- A depleted slot level is rendered as exhausted/greyed.
- An available higher-level slot tells the player which exhausted lower levels it can replace.
- The spellbook explains that, when a same-level slot is unavailable, the nearest available higher-level slot is consumed.

Casting/resource resolution remains owned by Character Engine and chat runtime code.
